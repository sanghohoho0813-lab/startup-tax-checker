# 창업감면 1분 판정기

세무·법인컨설팅 상담 현장에서 대표자 정보를 입력하면 **1분 안에 창업기업 관련 감면 가능성**을 1차 판정하는 웹앱입니다.

> 정확한 세액 계산기가 아니라, 상담 전용 **“가능 / 주의 / 불가 / 세무사 검토 필요”** 판정 도구입니다.

## 특징

- **4단계 종합판정**: 🟢 감면 가능성 높음 / 🟡 주의 필요 / 🟠 조건부 검토 / 🔴 불가 가능성 높음
- **한줄 결론**: 사장님이 3초 안에 이해할 수 있는 결론을 종합판정 카드 최상단에 표시
- **종합판정 기준**: 법인세·소득세 / 취득세 / 재산세 3개 핵심 항목으로만 판정. **등록면허세는 종합판정에서 제외**하고 별도 참고 영역으로 표시
- **상담 핵심 질문**: 결과에 따라 컨설턴트가 상담 시 바로 쓸 수 있는 질문을 자동 생성
- **계약 유도 영역**: "추가 확인 시 절세 가능성이 달라질 수 있습니다." 강조 + 전문가 상담 체크리스트(3~5개) 자동 생성
- **창업 제외사유 진단**: 법인전환·사업양수·동종 재창업·특수관계인 승계 예상 제외사유를 구체적으로 설명
- **연/월/일 분리 날짜 선택**: 연도 ±버튼 + 드롭다운 (생년월일 기본값 1980-01-01, 창업일 기본값 2020-01-01)
- **간결한 카카오톡 요약**: 고객 발송용 10줄 내외 요약문 자동 생성 + 복사 버튼
- **PDF 출력**: A4 1페이지 「창업감면 사전진단 결과서」 인쇄/PDF 저장
- **모바일 우선 UI**: 초기 화면은 종합판정·한줄결론·주요 확인사항만 노출, 세부 항목은 **상세보기 아코디언**으로 접어 스크롤 최소화
- 저장/로그인/DB 없이 **프론트엔드 단독 동작**

## 기술 스택

- React + TypeScript
- Vite
- Tailwind CSS

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행 (기본 http://localhost:5173)
npm run dev

# 3. 프로덕션 빌드
npm run build

# 4. 빌드 결과 미리보기
npm run preview
```

## 파일 구조

```
src/
├── App.tsx                    # 화면 구성 (입력 ↔ 결과 전환, 인쇄 처리)
├── main.tsx                   # 엔트리 포인트
├── index.css                  # Tailwind + 글꼴 + A4 인쇄 스타일
├── types.ts                   # 입력/판정 결과 타입 정의
├── lib/
│   ├── options.ts             # 선택지·라벨 (폼/요약/PDF 공용)
│   ├── date.ts                # 날짜 유틸 (만 나이, 연/월/일 분해 등)
│   ├── judgement.ts           # 종합 판정 + 항목별 판정 로직 (4단계)
│   ├── consult.ts             # 판정 사유·확인사항·상담질문·체크리스트 생성
│   ├── exclusion.ts           # 창업 제외사유 진단
│   ├── summary.ts             # 카카오톡 전송용 간결 요약문 생성
│   └── verdictStyle.ts        # 판정 상태별 스타일 토큰
└── components/
    ├── ui.tsx                 # 공용 UI (Section, ChoiceGroup, Accordion 등)
    ├── DateSelect.tsx         # 연/월/일 분리 날짜 선택
    ├── InputForm.tsx          # 입력 폼 (8개 항목)
    ├── ResultCards.tsx        # 결과 화면 오케스트레이션
    ├── OverallCard.tsx        # 종합 판정 + 한줄결론 + 주요 확인사항
    ├── ConsultCard.tsx        # 상담 핵심 질문 카드
    ├── ContractCta.tsx        # 계약 유도 + 전문가 상담 체크리스트
    ├── RegistrationReference.tsx  # 등록면허세 별도 참고 영역
    ├── ExclusionCard.tsx      # 창업 제외사유 진단 카드
    ├── ItemCard.tsx           # 항목별 판정 카드
    └── PrintSheet.tsx         # A4 PDF 결과서 (인쇄 전용)
```

## PDF 출력 방법

결과 화면의 **「PDF 출력」** 버튼을 누르면 브라우저 인쇄 창이 열립니다.
대상을 **PDF로 저장**으로 선택하면 A4 1페이지 결과서가 저장됩니다.
(별도 라이브러리 없이 브라우저 인쇄 기능과 `@media print` 스타일로 동작)
