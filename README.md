# 창업감면 1분 판정기

세무·법인컨설팅 상담 현장에서 대표자 정보를 입력하면 **1분 안에 창업기업 관련 감면 가능성**을 1차 판정하는 웹앱입니다.

> 정확한 세액 계산기가 아니라, 상담 전용 **“가능 / 주의 / 불가 / 세무사 검토 필요”** 판정 도구입니다.

## 특징

- **4개 항목 분리 판정**: 법인세·소득세 / 취득세 / 재산세 / 등록면허세
- **종합 판정 카드**: 초록(가능성 높음) / 노랑(주의) / 빨강(불가 가능성) / 회색(전문가 확인 필요)
- **상담 보조**: 항목별 판단 이유, 추가 확인사항, 상담 멘트 예시 제공
- **요약문 자동 생성**: 카카오톡/문자에 붙여넣기 좋은 요약문(오늘 날짜 포함) + 복사 버튼
- **모바일 우선**: Toss 느낌의 깔끔한 카드형 반응형 UI
- 저장/로그인/DB 없이 **프론트엔드 단독 MVP**

## 기술 스택

- React + TypeScript
- Vite
- Tailwind CSS

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행 (기본 http://localhost:5173)
npm run dev

# 3. 프로덕션 빌드
npm run build

# 4. 빌드 결과 미리보기
npm run preview
```

## 파일 구조

```
src/
├── App.tsx                    # 전체 화면 구성 (입력 ↔ 결과 전환)
├── main.tsx                   # 엔트리 포인트
├── index.css                  # Tailwind + 글꼴
├── types.ts                   # 입력/판정 결과 타입 정의
├── lib/
│   └── judgement.ts           # 판정 로직 + 요약문 생성
└── components/
    ├── InputForm.tsx          # 입력 폼 (8개 항목)
    └── ResultCards.tsx        # 종합 판정 카드 + 항목별 카드
```
